# Portefeuille de sites — Affiliation, Pub, Etsy

Ce dépôt contient la stratégie et (à terme) le code d'un portefeuille de sites web spécialisés
monétisés par affiliation, publicité display et produits numériques Etsy, avec le SEO Google et
Pinterest comme canaux d'acquisition. Voir `CLAUDE.md` pour le contexte complet.

## Documents stratégiques

- [`strategie/01-strategie-globale.md`](strategie/01-strategie-globale.md) — analyse de marché,
  analyse de la concurrence, sélection des niches (grille de notation /100), architecture du
  portefeuille, plan SEO/Pinterest/Etsy/affiliation transverse, automatisation, KPI, risques,
  feuille de route.
- [`strategie/02-site-tdah-productivite.md`](strategie/02-site-tdah-productivite.md) — Site A,
  productivité & organisation pour cerveaux TDAH/neuroatypiques (score 84/100, lancé en premier).
- [`strategie/03-site-petits-espaces.md`](strategie/03-site-petits-espaces.md) — Site B,
  organisation petits espaces & vie en location (score 79/100).
- [`strategie/04-site-micro-mariage.md`](strategie/04-site-micro-mariage.md) — Site C,
  micro-mariages & élopements (score 80/100).

## Résumé exécutif

3 sites, lancés séquentiellement (pas en parallèle), ciblant le marché anglophone US/UK pour
maximiser le potentiel de revenu (voir hypothèse détaillée dans le document 01). Priorité de
monétisation : affiliation d'abord, publicité display ensuite, produits Etsy en complément.
Aucun chevauchement de mots-clés entre les trois sites — persona commune ("reprendre le contrôle
face à la charge mentale"), marques et domaines strictement séparés.
